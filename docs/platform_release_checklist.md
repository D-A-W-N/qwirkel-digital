# Desktop-Release-Checkliste

## Allgemein

- [ ] App auf macOS, Linux und Windows buildbar
- [ ] Tests auf allen Desktop-Plattformen laufen
- [ ] Offizielle Build- und Startbefehle dokumentiert
- [ ] Versionierung und Build-Nummer konsistent

## macOS

- [ ] Signed/Notarized Build vorbereitet
- [ ] App-Icon und Splash gesetzt
- [ ] Privacy-Info geprüft

## Linux

- [ ] Debian/Ubuntu- und Flatpak-Workflow geprüft
- [ ] App-Icon und Desktop-Datei vorbereitet
- [ ] Start-Shortcut und Dateizuordnung geprüft

## Windows

- [ ] Installer- oder ZIP-Workflow geprüft
- [ ] App-Icon und Startmenü-Eintrag vorbereitet
- [ ] Signierung/Vertrauensstatus vorbereitet
