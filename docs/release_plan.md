# Release-Plan Qwirkle Digital

## Ziel

Die App soll als spielbare, getestete und releasefähige Desktop-App für macOS, Linux und Windows erscheinen.

## Prioritäten

1. Stabilität der Setup- und Spieloberfläche
2. Netzwerk- und Fehlerzustände für reale Nutzung absichern
3. Build- und Packaging-Setup für macOS, Linux und Windows vorbereiten
4. Release-Metadaten, Icons und Plattform-Integration ergänzen
