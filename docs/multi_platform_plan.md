# Mehrplattform-Plan Qwirkle Digital

## Ziel

Die App soll nicht nur auf macOS, sondern auch auf Linux und Windows zuverlässig laufen.

## Prioritäten

1. Plattformübergreifende Build-Prüfung für macOS, Linux und Windows
2. Plattform-spezifische Release-Metadaten und Icons vorbereiten
3. Netzwerk- und Speicherfunktionen für Desktop-Umgebungen absichern
4. Release-Pipeline für alle Zielplattformen vorbereiten

## Umsetzungsschritte

- [ ] Flutter-Targets für macOS, Linux und Windows verifizieren
- [ ] Build- und Startbefehle für alle drei Plattformen dokumentieren
- [ ] Desktop-Asset- und App-Metadaten für Linux/Windows vorbereiten
- [ ] Plattform-spezifische Testfälle für Setup und Spielablauf ergänzen
- [ ] Release-Checkliste für Desktop-Distribution erweitern
