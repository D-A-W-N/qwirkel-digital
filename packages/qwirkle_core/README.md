# qwirkle_core

Reine Spiellogik für Qwirkle Digital: Brett, Zugvalidierung (Kollinearität, Lückenlosigkeit, Farb-/Formregeln), Wertung, Beutelverwaltung, Startspieler-Bestimmung und die Bot-KI (Easy/Medium/Hard). Kein Flutter/UI-Code — plattform- und transportunabhängig, wird sowohl von der App als auch von [qwirkle_net](../qwirkle_net) verwendet.

Siehe [Root-README](../../README.md) für Setup und Testbefehle.
